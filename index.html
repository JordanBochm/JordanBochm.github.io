Proyectos

Automatización de Guías — Integración API Estafeta

El equipo de operaciones en SEKO Logistics generaba guías de envío de forma manual a través del portal web de Estafeta, procesando cada orden individualmente. Con volúmenes de decenas de órdenes diarias, el proceso era lento y propenso a errores de captura.

Mi rol: Diseñé y desarrollé un sistema en Python que se conecta directamente a la API REST de Estafeta (autenticación OAuth2 vía Azure AD/CIAM), lee las órdenes desde archivos Excel (Combined Reports), construye los payloads JSON con validación de direcciones, genera las guías vía POST a /labelrest/v1/wayBills, descarga las etiquetas PDF y produce un reporte de resumen automático. También implementé un flujo de 2 pasos (preview → generación) para que operaciones pueda revisar antes de enviar.

Python REST API OAuth2 Estafeta API pandas openpyxl requests

En producción en SEKO Logistics desde septiembre 2026. Reemplazó el proceso manual de generación de guías, reduciendo el tiempo de procesamiento por lote de órdenes.

Integración FedEx API & Call Tags en techSHIP

El equipo de logística requería automatizar las recolecciones de retorno (Call Tags) sin entrar manualmente al portal de FedEx, donde se enfrentaban a errores de sincronización y validación de fechas que bloqueaban la operación.

Mi rol: Lideré la integración configurando las credenciales en techSHIP y habilitando los módulos Pickup Request API y End of Day Close API. Diseñé el flujo para disparar Call Tags automáticos. Además, analicé el comportamiento de la API vs el portal de FedEx, resolviendo los errores de "envío no encontrado" mediante el ajuste de fechas (Ship Date) y la sincronización forzada (EOD), entregando un SOP (Procedimiento Operativo Estándar) oficial para el equipo.

techSHIP FedEx API SOP / Tech Writing Troubleshooting

Eliminación total de la carga manual para agendar recolecciones de retorno y creación del procedimiento estándar de operación.
